# Contratos de intercambio

Borrador v1 de sobre de eventos y acuse durable, expresado como tipos TypeScript sin validación en tiempo de ejecución, entidades ORM, DTO de AX ni dependencias de frameworks. Productores y consumidores aún no están implementados; el contrato requiere validación de payload, límites, canonicalización/hash, compatibilidad y deduplicación transaccional antes de publicarse. Un acuse no significa pago aprobado, DTE aceptado o ERP contabilizado. No existe endpoint que emita estos acuses en el scaffold.
