# Shared kernel

Tipos mínimos de país, moneda, dinero en unidades menores y ámbito de operación (`OperationScope`: país, entidad legal y sucursal). Sin Nest, Angular, ORM ni acceso a servicios. No contiene modelos completos de ventas o proveedores. Los tipos TypeScript no validan entradas HTTP ni autorizan acceso; esas comprobaciones son trabajo pendiente. El dominio mock CLP existente permanece separado.
