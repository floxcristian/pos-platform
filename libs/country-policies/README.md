# Políticas por país

Entrada pura para perfiles versionados de Chile, Perú y España. El scaffold solo define el tipo `CountryProfile`: no incluye perfiles configurados, validación en tiempo de ejecución, cálculo de impuestos ni adaptadores fiscales o de pago. Los identificadores de proveedores del contrato no habilitan esos servicios ni operaciones offline. Las políticas se agregarán con reglas verificadas y casos de conformidad, evitando condicionales de país dispersos en ventas. No se crea una app distinta por país.
